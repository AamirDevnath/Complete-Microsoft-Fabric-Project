# Complete-Microsoft-Fabric-Project-
Complete Microsoft Fabric Project | Lakehouse, Warehouse, Dataflow, SQL &amp; Power BI Integration

This project implements an end-to-end data analytics workflow using Microsoft Fabric to manage employee data, project budgets, and salary information.

**Microsoft Fabric End-to-End Analytics Project**
A comprehensive data engineering and analytics solution built on Microsoft Fabric. This project transforms raw CSV data into actionable insights for workforce management and financial risk assessment.

**Key Technologies**
Microsoft Fabric: Lakehouse, Warehouse, Dataflows Gen2, Pipelines, Semantic Models.
Power BI: Data visualization, DAX measures, interactivity.
SQL: Complex querying, CTEs, Joins, Views.

**Project Workflow**
Data Ingestion: Uploaded raw CSV files (employee data, salary, budgets) to a Fabric Lakehouse.
ETL/Data Transformation: Utilized Dataflows Gen2 to clean, transform, and map raw data into structured Delta tables within a SQL Warehouse.
Data Modeling & SQL: Developed complex SQL queries using CTEs, Joins, and Unions to create a unified view for reporting. Designed a Semantic Model with relationships (one-to-one, one-to-many) and DAX measures.
Data Visualization: Built an interactive Power BI report featuring employee profiles, project status donuts, and budget versus cost analyses.
Automation: Configured a Data Pipeline to automate the Dataflow and refresh the Semantic Model on a daily schedule.
